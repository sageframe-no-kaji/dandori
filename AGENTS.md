# dandori — project instructions

Work in this repo shapes the dandori spec format — how bounded agent tasks are authored, what makes a good spec, how to detect gaps. Reasoning about the format requires the operating discipline's rationale in scope.

Read the [operating discipline rationale](https://github.com/sageframe-no-kaji/ho-system/blob/main/practitioner/operating-discipline-rationale.md) before changing the spec format. A local copy in the practitioner’s Ho modules or framework checkout also serves.
